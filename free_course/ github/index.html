The 5-Minute Mental Model

✓

Before touching a single command, you need this distinction locked in. Most beginners confuse these two — and it makes everything else harder.

🔧 Git = The Tool

A version control system that runs on your computer. It tracks every change you make to files over time.

☁️ GitHub = The Place

A cloud platform that hosts Git repositories. It adds collaboration, PRs, and automation on top of Git.

Git tracks changes locally. GitHub syncs them to the cloud.
💡 Key insight: You can use Git without GitHub. You cannot use GitHub without Git.
Quick check: Which one runs on your local computer?

Common Mistakes & Fixes

✓

❌ Committing a secret

Pushed .env with a real key. Deleting doesn't remove it from history.

✅ Fix: Rotate the key immediately. Add to .gitignore. Use trufflehog for cleanup.

❌ Committing to main directly

Bypassed review, possibly broke the build.

✅ Fix: Enable branch protection. Use git revert <sha> to undo cleanly.

❌ Merge conflict panic

Force-pushing loses work.

✅ Fix: Edit conflicting file, keep what you want, delete markers, git add . && git commit.

❌ Force-pushing shared branches

Erases teammates' commits.

✅ Fix: Use --force-with-lease. Better: never force-push shared branches.

❌ Committing node_modules/

Repo bloats with dependencies.

✅ Fix: Add to .gitignore. If committed: git rm -r --cached node_modules.

❌ Vague commit messages

"fix", "update", "asdf".

✅ Fix: Imperative mood: Add login validation.
