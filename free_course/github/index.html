The 5-Minute Mental Model

✓

Before touching a single command, you need this distinction locked in. Most beginners confuse these two — and it makes everything else harder.

🔧 Git = The Tool

A version control system that runs on your computer. It tracks every change you make to files over time.

☁️ GitHub = The Place

A cloud platform that hosts Git repositories. It adds collaboration, PRs, and automation on top of Git.

Key insight: You can use Git without GitHub. You cannot use GitHub without Git.

Setup & Security

✓

Let's get you a real GitHub identity — and lock it down properly from day one.

1.1 Create Your Account

  1. Go to github.com/signup
  2. Enter email, password, username
  3. Verify your email

1.2 Turn On 2FA

Two-factor authentication is mandatory. Save your recovery codes.

1.3 Install Git

# macOS
brew install git

# Windows: download from git-scm.com
# Linux
sudo apt install git

1.4 Configure Your Identity

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

02

Your First Repository

✓

A repository (repo) is a project folder that Git tracks with full history.

2.1 Create a Repo

  1. Click the + → New repository
  2. Name it hello-github
  3. Choose Public
  4. Add a README
  5. Create repository

2.2 What is .gitignore?

# Secrets
.env
*.key

# Dependencies
node_modules/

⚠️ Critical: Once committed to a public repo, a secret is permanently compromised.

Branches & Pull Requests

✓

A branch is a parallel version. Experiment safely, then merge when ready.

git switch -c feature/my-change
git switch main
git branch -d feature/my-change

🔒 Golden Rule: Never commit directly to main on a shared project.

GitHub Actions

✓

Actions runs automated workflows on events like push or PR.

name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npm test

Common Mistakes

✓

❌ Committing to main directly

Fix: Enable branch protection.

❌ Vague commit messages

Fix: Use imperative: "Add login validation".
